Lienzo Java · TeaVM

An alpha port of Lienzo's canvas API. This first example exercises layers, shapes, text, hit detection and dragging using the same Java source under GWT and TeaVM.

Starting…

Click the rectangle to select it. Drag either shape to move it. Restore last drag uses Lienzo's existing DragContext.reset() API. It restores only the most recent drag; there is no general undo/redo stack. Reset positions reloads the example's starting coordinates.

Original library: Lienzo, by Ahome and KIE contributors.
